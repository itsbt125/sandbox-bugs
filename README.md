# Sandbox issues

[Bug reports](https://github.com/itsbt125/sandbox-bugs/issues/new?template=bug_report.yml) and feature requests for [Sandbox](https://sandbox.btea.dev).

## Before opening an issue

- Search [existing issues](https://github.com/itsbt125/sandbox-bugs/issues) first.
- Open one issue per bug or request.
- Remove credentials, API keys, cookies, private URLs, and personal information from screenshots and logs.
- Do not upload malware or samples. Link the analysis or include its SHA-256 instead.
- Do not report security issues in a public issue. Use the [security page](https://sandbox.btea.dev/security).

## Bugs

Use the [bug report form](https://github.com/itsbt125/sandbox-bugs/issues/new?template=bug_report.yml). Include:

- What happened
- What you expected
- Steps to reproduce
- Screenshots, if they help
- Browser, operating system, and device
- Whether it happens every time and on another device

If the bug only happens on one report, include its URL or analysis ID and the approximate time in UTC. Do not attach the sample.

## Features

Use the [feature request form](https://github.com/itsbt125/sandbox-bugs/issues/new?template=feature_request.yml). Include:

- The problem you want solved
- What you want to happen, with an example if possible
- Other tools that do something similar, or workarounds you use now

Requests may be closed if they are out of scope, unsafe, or already covered.

## Security

Do not open a public issue for a vulnerability, credential leak, privacy problem, authentication bypass, or abuse vector. Report it through the [Sandbox security page](https://sandbox.btea.dev/security). Include enough detail to reproduce it privately, and do not access data that is not yours.

## What this repo is for

This repo is for bugs and feature requests for Sandbox. It is not for sample submissions, threat-intelligence feeds, or requests to analyze a sample. Use the site for that. For abuse or legal requests, use the contact route on the [terms and abuse page](https://sandbox.btea.dev/terms).
